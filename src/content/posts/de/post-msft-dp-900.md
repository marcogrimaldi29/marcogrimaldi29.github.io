## 🔐 DP-900 Überblick: Azure Data Fundamentals

**❗ Kurzer Hinweis:** Diese Review spiegelt ausschließlich meine persönliche Erfahrung wider. Sie ist in keiner Weise gesponsert oder unterstützt.
{: .notice--info}

### ℹ️ Einleitung

Mein Ziel mit der Zertifizierung **DP-900**: Azure Data Fundamentals war es, meine allgemeine Datenkompetenz zu vertiefen und zu sehen, wie sich der Ansatz von Microsoft mit dem vergleicht, was ich im [Google Data Analytics Professional Certificate](/de/cert-reviews/google-data-analytics/) gelernt habe. DP-900 behandelt die **Grundlagen von Datenspeicherung, Datenverarbeitung, Analytics und Visualisierung innerhalb von Azure, einschließlich zentraler Datenkonzepte, relationaler und nicht-relationaler Dienste sowie gängiger Daten-Workloads**. Zusammen bieten diese Themen einen klaren Blick darauf, wie Microsoft seine Datenplattform strukturiert und wie diese Dienste in realen Lösungen angewendet werden. Es ist eine ausgezeichnete Möglichkeit, ein rundes Verständnis moderner Datenprinzipien aufzubauen.

---

### 🛢️ Warum DP-900 wichtig ist

**Daten sind das Rückgrat des modernen Geschäfts**, und zu wissen, wie man sie effektiv verwaltet, speichert und interpretiert, ist essenziell. Die DP-900-Zertifizierung bietet ein solides Fundament in zentralen Datenkonzepten und den Azure-Diensten, die sie unterstützen, und ist damit ein idealer Ausgangspunkt für alle, die datenbezogene Rollen innerhalb des Microsoft-Ökosystems anstreben.

Über Azure hinaus ist **ein Großteil des in DP-900 behandelten Wissens** — von Datenbankgrundlagen bis zu Analytics-Workloads — **auch auf andere Cloud-Plattformen und Branchenwerkzeuge anwendbar**. Das macht sie zu einer vielseitigen, anbieterunabhängigen Zertifizierung, die sowohl das Angebot von Microsoft als auch breitere Karrierewege im Datenbereich ergänzt.

---

### 📊 Bewertete Kompetenzen (aktualisiert am 1. November 2024)

Die **[bewerteten Kompetenzen](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-900#skills-measured-as-of-november-1-2024) für die DP-900-Prüfung** verteilen sich auf vier Hauptwissensdomänen. Jede ist unterschiedlich in der Prüfung gewichtet:

- **Zentrale Datenkonzepte beschreiben (25–30%)**
  - Die Arten zentraler Daten-Workloads beschreiben (transaktional, analytisch)
  - Datenrollen und -dienste beschreiben
  - Konzepte der Datenverarbeitung beschreiben (Batch, Streaming, Echtzeit)
  - Konzepte der Datenspeicherung beschreiben (strukturiert, halbstrukturiert, unstrukturiert)

- **Überlegungen zu relationalen Daten in Azure identifizieren (20–25%)**
  - Relationale Datenstrukturen beschreiben (Tabellen, Spalten, Zeilen, Indizes)
  - Relationale Datenbankdienste in Azure beschreiben (Azure SQL Database, Azure SQL Managed Instance, SQL Server auf Azure-VMs)
  - Bereitstellungs- und Deployment-Optionen für relationale Daten identifizieren
  - Grundlegende Verwaltungsaufgaben beschreiben (Sicherheit, Backup, Wiederherstellung, Skalierung)

- **Überlegungen zur Arbeit mit nicht-relationalen Daten in Azure beschreiben (15–20%)**
  - Nicht-relationale Datenstrukturen beschreiben (Key-Value, Dokument, Graph, Column-Family)
  - Nicht-relationale Datendienste in Azure beschreiben (Azure Cosmos DB, Azure Table Storage, Azure Blob Storage)
  - Szenarien für nicht-relationale Datenlösungen identifizieren

- **Eine Analytics-Workload in Azure beschreiben (25–30%)**
  - Analytics-Konzepte beschreiben (Data Warehousing, Big Data, Echtzeit-Analytics)
  - Analytics-Dienste in Azure beschreiben (Azure Synapse Analytics, Azure Data Lake, Azure Databricks, Azure HDInsight)
  - Werkzeuge zur Datenvisualisierung identifizieren (Power BI)
  - Grundprinzipien von Datenaufnahme, -transformation und -visualisierung beschreiben

### 💡 Praktische Tipps zum Bestehen der DP-900

* **Nutze die offiziellen Microsoft-Learn-Pfade**: Verwende die [kostenlosen Lernmodule](https://learn.microsoft.com/en-us/training/courses/dp-900t00) von Microsoft, die direkt der Prüfungsgliederung folgen und regelmäßig aktualisiert werden.
* **Nutze Übungsprüfungen strategisch**: Die [Übungsbewertungen](https://learn.microsoft.com/en-us/credentials/certifications/practice-assessments-for-microsoft-certifications) von Microsoft sind eng an den Test angelehnt und heben verbesserungsbedürftige Bereiche hervor.
* **Verfolge Schwachstellen**: Die Übungsbewertungen liefern eine Aufschlüsselung deiner Leistung, sodass du das Wiederholen leichter dort fokussieren kannst, wo es am nötigsten ist.
* **Kenne die Prüfungsmechanik**:
  - Erwarte ~40–60 Fragen im Multiple-Choice-, Drag-and-Drop- oder Wahr/Falsch-Format.
  - Du hast [~45 Minuten](https://learn.microsoft.com/en-us/credentials/support/exam-duration-exam-experience#exam-duration), um den Test abzuschließen, brauchst eine Punktzahl von [700/1000](https://learn.microsoft.com/en-us/credentials/certifications/exam-scoring-reports#scores-needed-to-pass-exams) zum Bestehen und kannst zwischen Online-Proctoring oder einem Pearson-VUE-Zentrum vor Ort wählen.

Entdecke gern auf eigene Faust neue Inhalte, aber wenn du dich überfordert fühlst, konzentriere dich auf das, was du weißt, und vertraue deinem Instinkt — dieses Bauchgefühl liegt oft richtig, und die unten stehenden Ressourcen sollten mehr als genug sein, um die Prüfung zu meistern.
* **Schau dir das [Study-Cram-Video von John Savill](https://www.youtube.com/watch?v=0gtpasITVnk) an**. Das Gleiche wie bei jeder anderen Azure-bezogenen Prüfung: John Savills Videos sind eine fantastische Möglichkeit, das Wesentliche ansprechend und praxisnah zu destillieren.
* **Absolviere den offiziellen [DP-900-Kurs](https://learn.microsoft.com/en-us/training/courses/dp-900t00) von Microsoft**. Er ist umfassend, kostenlos und wird durchgehend aktualisiert.
* **Schau dir das [Study Cram von John Savill](https://www.youtube.com/watch?v=0gtpasITVnk)** nach Abschluss der Lernpfade noch einmal an. Es kann dir helfen, Schlüsselpunkte zu verstärken und etwaige Schwachstellen zu schließen.
* **Sei am Prüfungstag selbstbewusst und gib dein Bestes**. Wenn du den Test ablegst, hast du dir durch das Durcharbeiten dieser Materialien ein solides Fundament aufgebaut.
