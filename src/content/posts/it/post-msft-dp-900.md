## 🔐 Panoramica DP-900: Azure Data Fundamentals

**❗ Una premessa:** questa recensione riflette esclusivamente la mia esperienza personale. Non è sponsorizzata né approvata in alcun modo.
{: .notice--info}

### ℹ️ Introduzione

Il mio obiettivo con la certificazione **DP-900: Azure Data Fundamentals** era approfondire la mia alfabetizzazione complessiva sui dati e vedere come l’approccio di Microsoft si confronta con ciò che avevo imparato durante il [Google Data Analytics Professional Certificate](/it/cert-reviews/google-data-analytics/). DP-900 copre i **fondamenti di archiviazione, elaborazione, analisi e visualizzazione dei dati in Azure, inclusi concetti chiave sui dati, servizi relazionali e non relazionali e carichi di lavoro dati comuni**. Insieme, questi argomenti offrono una visione chiara di come Microsoft struttura la sua piattaforma dati e di come questi servizi vengono applicati in soluzioni reali. È un ottimo modo per costruire una comprensione completa dei moderni principi sui dati.

---

### 🛢️ Perché DP-900 è importante

**I dati sono la spina dorsale del business moderno** e saperli gestire, archiviare e interpretare in modo efficace è essenziale. La certificazione DP-900 offre una solida base sui concetti fondamentali dei dati e sui servizi Azure che li supportano, rendendola un punto di partenza ideale per chiunque punti a ruoli legati ai dati nell’ecosistema Microsoft.

Oltre ad Azure, **gran parte delle conoscenze trattate in DP-900** — dai fondamenti dei database ai carichi di lavoro analitici — **si applica anche ad altre piattaforme cloud e a strumenti di settore**. Questo la rende una certificazione versatile e indipendente dal vendor, che completa sia l’offerta di Microsoft sia percorsi di carriera più ampi nel mondo dei dati.

---

### 📊 Competenze valutate (aggiornate al 1° novembre 2024)

Le **[competenze valutate](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-900#skills-measured-as-of-november-1-2024) per l’esame DP-900** rientrano in quattro domini di conoscenza principali, ciascuno con un peso diverso nell’esame:

- **Descrivere i concetti chiave sui dati (25–30%)**
  - Descrivere i tipi di carichi di lavoro dati principali (transazionali, analitici)
  - Descrivere ruoli e servizi legati ai dati
  - Descrivere i concetti di elaborazione dei dati (batch, streaming, real-time)
  - Descrivere i concetti di archiviazione dei dati (strutturati, semi-strutturati, non strutturati)

- **Identificare considerazioni sui dati relazionali in Azure (20–25%)**
  - Descrivere le strutture dati relazionali (tabelle, colonne, righe, indici)
  - Descrivere i servizi di database relazionali in Azure (Azure SQL Database, Azure SQL Managed Instance, SQL Server su VM Azure)
  - Identificare opzioni di provisioning e distribuzione per i dati relazionali
  - Descrivere le attività di gestione di base (sicurezza, backup, ripristino, scalabilità)

- **Descrivere considerazioni sull’uso di dati non relazionali in Azure (15–20%)**
  - Descrivere le strutture dati non relazionali (key-value, document, graph, column-family)
  - Descrivere i servizi di dati non relazionali in Azure (Azure Cosmos DB, Azure Table Storage, Azure Blob Storage)
  - Identificare scenari per soluzioni di dati non relazionali

- **Descrivere un carico di lavoro analitico in Azure (25–30%)**
  - Descrivere i concetti di analytics (data warehousing, big data, analisi in tempo reale)
  - Descrivere i servizi di analytics in Azure (Azure Synapse Analytics, Azure Data Lake, Azure Databricks, Azure HDInsight)
  - Identificare gli strumenti di visualizzazione dei dati (Power BI)
  - Descrivere i principi di base di ingestione, trasformazione e visualizzazione dei dati

### 💡 Consigli pratici per superare l’esame DP-900

- **Sfrutta i percorsi ufficiali di Microsoft Learn**: usa i [moduli gratuiti](https://learn.microsoft.com/en-us/training/courses/dp-900t00) di Microsoft, che seguono direttamente la traccia dell’esame e sono aggiornati regolarmente.
- **Usa i test di pratica in modo strategico**: le [valutazioni di pratica](https://learn.microsoft.com/en-us/credentials/certifications/practice-assessments-for-microsoft-certifications) di Microsoft sono molto allineate al test ed evidenziano le aree da migliorare.
- **Tieni traccia delle aree deboli**: le valutazioni di pratica forniscono un’analisi delle tue prestazioni, facilitando il ripasso dove serve di più.
- **Conosci la meccanica dell’esame**:
  - Aspettati ~40–60 domande in formato a risposta multipla, drag-and-drop o vero/falso.
  - Avrai [~45 minuti](https://learn.microsoft.com/en-us/credentials/support/exam-duration-exam-experience#exam-duration) per completare il test, ti serve un punteggio di [700/1000](https://learn.microsoft.com/en-us/credentials/certifications/exam-scoring-reports#scores-needed-to-pass-exams) per superarlo, e puoi scegliere tra proctoring online o un centro Pearson VUE in presenza.

### 🗂️ Strategia di studio

Per questa certificazione — e per le altre Fundamentals che ho conseguito — ho generalmente seguito questo approccio:

- **Raccogli e organizza tutte le risorse rilevanti** e tienile a portata di mano. Sentiti libero di scoprire nuovi contenuti per conto tuo ma, se ti senti sopraffatto, concentrati su ciò che conosci e fidati del tuo istinto: quella sensazione è spesso giusta, e le risorse qui sotto dovrebbero bastare ampiamente per superare l’esame.
- **Guarda lo [Study Cram di John Savill](https://www.youtube.com/watch?v=0gtpasITVnk)**. Come per ogni altro esame Azure: i video di John Savill sono un modo fantastico per distillare l’essenziale in modo coinvolgente e pratico.
- **Completa il [corso ufficiale DP-900](https://learn.microsoft.com/en-us/training/courses/dp-900t00) di Microsoft**. È completo, gratuito e aggiornato con costanza.
- **Riguarda la [sessione Study Cram di John Savill](https://www.youtube.com/watch?v=0gtpasITVnk)** dopo aver completato i percorsi di apprendimento. Può aiutarti a rinforzare i punti chiave e colmare le aree deboli.
- **Sii sicuro e dai il massimo il giorno dell’esame**. Quando ti siederai per il test, avrai costruito una base solida grazie a questi materiali.
