## 🔐 Panorama DP-900: Azure Data Fundamentals

**❗ Una aclaración:** esta reseña refleja únicamente mi experiencia personal. No está patrocinada ni avalada de ningún modo.
{: .notice--info}

### ℹ️ Introducción

Mi objetivo con la certificación **DP-900**: Azure Data Fundamentals era profundizar en mi alfabetización general en datos y ver cómo se compara el enfoque de Microsoft con lo que aprendí durante el [Google Data Analytics Professional Certificate](/es/cert-reviews/google-data-analytics/). DP-900 cubre los **fundamentos del almacenamiento, el procesamiento, la analítica y la visualización de datos en Azure, incluidos los conceptos básicos de datos, los servicios relacionales y no relacionales, y las cargas de trabajo de datos comunes**. En conjunto, estos temas ofrecen una visión clara de cómo Microsoft estructura su plataforma de datos y cómo se aplican estos servicios en soluciones reales. Es una forma excelente de construir una comprensión integral de los principios de datos modernos.

---

### 🛢️ Por qué importa DP-900

**Los datos son la columna vertebral de la empresa moderna**, y saber gestionarlos, almacenarlos e interpretarlos de forma eficaz es esencial. La certificación DP-900 ofrece una base sólida en los conceptos básicos de datos y en los servicios de Azure que los sustentan, lo que la convierte en un punto de partida ideal para cualquiera que aspire a puestos relacionados con los datos dentro del ecosistema de Microsoft.

Más allá de Azure, **gran parte del conocimiento que cubre DP-900** — desde los fundamentos de las bases de datos hasta las cargas de trabajo de analítica — **también es aplicable a otras plataformas cloud y herramientas del sector**. Esto la convierte en una certificación versátil e independiente del proveedor que complementa tanto la oferta de Microsoft como itinerarios profesionales de datos más amplios.

### 📊 Competencias evaluadas (actualizadas al 1 de noviembre de 2024)

Las **[competencias evaluadas](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-900#skills-measured-as-of-november-1-2024) para el examen DP-900** se reparten en cuatro dominios de conocimiento principales. Cada uno tiene un peso diferente en el examen:

- **Describir conceptos básicos de datos (25–30%)**
  - Describir los tipos de cargas de trabajo de datos básicas (transaccionales, analíticas)
  - Describir los roles y servicios de datos
  - Describir los conceptos de procesamiento de datos (por lotes, en streaming, en tiempo real)
  - Describir los conceptos de almacenamiento de datos (estructurados, semiestructurados, no estructurados)

- **Identificar consideraciones para datos relacionales en Azure (20–25%)**
  - Describir las estructuras de datos relacionales (tablas, columnas, filas, índices)
  - Describir los servicios de bases de datos relacionales en Azure (Azure SQL Database, Azure SQL Managed Instance, SQL Server en VM de Azure)
  - Identificar las opciones de aprovisionamiento y despliegue para datos relacionales
  - Describir las tareas básicas de gestión (seguridad, copia de seguridad, restauración, escalado)

- **Describir consideraciones para trabajar con datos no relacionales en Azure (15–20%)**
  - Describir las estructuras de datos no relacionales (clave-valor, documento, grafo, familia de columnas)
  - Describir los servicios de datos no relacionales en Azure (Azure Cosmos DB, Azure Table Storage, Azure Blob Storage)
  - Identificar escenarios para soluciones de datos no relacionales

- **Describir una carga de trabajo de analítica en Azure (25–30%)**
  - Describir los conceptos de analítica (data warehousing, big data, analítica en tiempo real)
  - Describir los servicios de analítica en Azure (Azure Synapse Analytics, Azure Data Lake, Azure Databricks, Azure HDInsight)
  - Identificar las herramientas de visualización de datos (Power BI)
  - Describir los principios básicos de ingesta, transformación y visualización de datos

### 💡 Consejos prácticos para aprobar el DP-900

* **Aprovecha los itinerarios oficiales de Microsoft Learn**: usa los [módulos de aprendizaje gratuitos](https://learn.microsoft.com/en-us/training/courses/dp-900t00) de Microsoft, que siguen directamente la traza del examen y se actualizan con regularidad.
* **Usa los exámenes de práctica de forma estratégica**: las [evaluaciones de práctica](https://learn.microsoft.com/en-us/credentials/certifications/practice-assessments-for-microsoft-certifications) de Microsoft están muy alineadas con el test y resaltan las áreas que necesitan mejorar.
* **Lleva un seguimiento de las áreas débiles**: las evaluaciones de práctica ofrecen un desglose de tu rendimiento, lo que facilita centrar el repaso donde más se necesita.
* **Conoce la mecánica del examen**:
  - espera ~40–60 preguntas en formato de opción múltiple, arrastrar y soltar o verdadero/falso.
  - dispondrás de [~45 minutos](https://learn.microsoft.com/en-us/credentials/support/exam-duration-exam-experience#exam-duration) para completar el test, necesitas una puntuación de [700/1000](https://learn.microsoft.com/en-us/credentials/certifications/exam-scoring-reports#scores-needed-to-pass-exams) para aprobar, y puedes elegir entre supervisión en línea o un centro Pearson VUE presencial.

### 🗂️ Estrategia de estudio

Para esta certificación — y otras Fundamentals que obtuve — generalmente me ceñí a este enfoque:

* **Reúne y organiza todos los recursos relevantes** y tenlos a mano. Siéntete libre de descubrir contenido nuevo por tu cuenta, pero si te sientes abrumado, céntrate en lo que sabes y confía en tu instinto, esa intuición tuya suele acertar — y los recursos de abajo deberían bastar de sobra para aprobar el examen.
* **Mira el [vídeo Study Cram de John Savill](https://www.youtube.com/watch?v=0gtpasITVnk)**. Lo de siempre con cualquier examen relacionado con Azure: los vídeos de John Savill son una forma fantástica de destilar lo esencial de manera amena y práctica.
* **Completa el [curso oficial DP-900](https://learn.microsoft.com/en-us/training/courses/dp-900t00) de Microsoft**. Es completo, gratuito y se actualiza con constancia.
* **Vuelve a ver el [Study Cram de John Savill](https://www.youtube.com/watch?v=0gtpasITVnk)** tras completar los itinerarios de aprendizaje. Puede ayudarte a reforzar los puntos clave y apuntalar cualquier área débil.
* **Ten confianza y da lo mejor de ti el día del examen**. Cuando te sientes a hacer el test, habrás construido una base sólida tras recorrer estos materiales.

### 🎟️ Vales y descuentos del examen

Cuando hice el DP-900 por primera vez a principios de 2023, tuve la suerte de obtener un vale de examen gratuito a través de un **Microsoft Virtual Training Day** centrado en Azure Data Fundamentals y que cubría el contenido de esta certificación, como ocurrió con otras formaciones y certificados. Puedes leer más sobre mi experiencia con el [SC-900](/es/cert-reviews/microsoft-sc-900/), el [PL-900](/es/cert-reviews/microsoft-pl-900/), el [AZ-900](/es/cert-reviews/microsoft-az-900/) y el [AI-900](/es/cert-reviews/microsoft-ai-900/) haciendo clic en ellos.

A fecha de 2025 y hasta donde sé, Microsoft sigue ofreciendo este tipo de oportunidades de forma periódica, aunque normalmente vinculadas a eventos o promociones concretos. Así que, si estás considerando el DP-900, te recomiendo encarecidamente estar atento a [Microsoft Events](https://www.microsoft.com/en-us/events) o suscribirte a boletines que puedan avisarte de próximos training days o iniciativas similares. Estos eventos pueden ser una gran manera de profundizar en tu comprensión de los servicios de Azure y, de paso, conseguir un vale de examen gratuito.
